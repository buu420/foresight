## Change and evidence

The user's 0.2.2 run correctly spoke New Game settings and Start Game, then
failed because the mod expected three main controls on the naming screen. Native
construction has four: Defaults, Accept, the name field, and the character-grid
button. Version 0.2.3 correlates all four, including native initial focus on the
name field. Keyboard name entry now validates the correct buttons disabled and
re-enabled around typing: Defaults, Accept and the grid button.

See [the native audit](../native-audits/2026-09-10-name-entry-controls.md). Codex
checked the native builder, state construction, binding loop and keyboard entry
bodies in Ghidra. Claude independently confirmed the four controls and reviewed
the implementation; its follow-up verified the literal key-2 and key-3 writes
and their insertion sites. The wordless controls use authored English functional
descriptions; Defaults and Accept retain the game's localized strings.
