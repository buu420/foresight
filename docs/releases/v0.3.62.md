# Foresight 0.3.62 beta

Verified Nu NPCs now appear in **People** as Nu. The Keeper's Dome construct
uses **Nu, Strange Construct**, retaining its visible game name without
revealing its later identity. Hidden Nu and battle-only placements keep their
native availability and categories.

Closed sealed doors keep their useful labels on later visits. The two markers
for each Keeper's Dome doorway produce one target with both native interaction
approaches. Opened doors leave the object list. Locked doors remain identifiable
without allowing routes through them.

The **Pyramid** in Forest Ruins is an object destination while its seal is
present. Both navigation modes approach its native trigger row. Opening uses
the game's pendant check and automatic approach event; the mod does not press
Confirm or reveal what is inside before the game shows it.

The **Epoch dock** appears in Interactable Objects when the Epoch is actually
parked at the End of Time and the native boarding interaction is available.
Guidance reaches the dock and the game opens its own boarding choice. The
player answers that choice. A misleading encounter at this same position is
removed.

Optional quests no longer advertise the audited unintroduced requests from
other rooms, world maps or the End of Time. Choosing to preserve a sapling
alone no longer reveals Fiona's later request. Accepted and progressed quests
remain available. Directions through a passage toward a remote objective are
in **Story Events**, while actual local NPCs remain in People.

Three Nu actions and the Epoch's first-travel animated movie now have recorded
descriptions in the creator's approved Fish narration voice. The movie uses
the native movie session and original soundtrack. All 156 previous recordings,
including the opening movie, remain byte-identical. No account or network
connection is needed for playback.

Native scripts, fresh read-only Ghidra exports, installed map terrain,
rendered Nu frames and the exact original movie support the changes.
Automated tests cover both guidance modes, hidden objects, locks, repeat
interactions, parked/absent Epoch states, quest introductions, narration
resources and preservation. This is not a live gameplay or listening test;
tester confirmation of traversal, controller behavior and audible timing is
still needed. Later accepted-quest puzzle instructions were outside the
bounded introduction audit.

See [native evidence](../native-audits/2026-10-15-epoch-nu-and-seals.md) and
[Epoch narration timing](../movie-narration-0362.md).

Close the game before updating. Use `Foresight-v0.3.62-beta-win-x86.zip` for
standalone installation or `Foresight-v0.3.62-beta-amm.zip` through Accessibility
Mod Manager.
