# Foresight 0.3.56 beta

This update addresses the tester reports from Fiendlord's Keep and adds the
missing movie descriptions through that part of the story.

- Verified Ozzie and Kino appearances use their native names in People after
  their story introductions. Unrelated actors using the same sprites keep
  their appearance labels.
- Manual guidance and auto-walk wait when native creature collision temporarily
  blocks a route that otherwise exists. They recheck and continue when it clears.
  Auto-walk sends no movement while waiting. A visible blocker is named only
  when it matches the native contact; no battle or interaction is automated.
- Opening or returning to the main menu no longer repeats every party card.
  Tech details omit background Level and HP rows. Single Techs also omit repeated
  current MP; Dual and Triple Techs retain the rendered partners' MP and costs.
  Character and party-target selections still read their relevant stats.
- Included narration covers Ayla's rescue, Frog opening the Magic Cave, and the
  approach to Magus. All three use Fish recordings from the approved narrator
  voice. The previous 146 opening and story recordings are unchanged.
- Native movie sessions control narration timing, pause, skip and cleanup.
  Verified separately installed tracks take precedence. The original soundtrack
  keeps its gain. Story-action recordings are canceled and held actions cleared
  while these native movies cover the field.
- Native movie failures receive one spoken failure message per player session.
  An asynchronous failure still requires the game's movie-skip control.

Testing covers native name gates, route replay and blocker identity, menu focus,
rendered Tech row names, the real embedded movie tracks, lifecycle cancellation,
and playback failure observation. Silent x86 probes use the actual game library
and production detours to check all three original movies, existing separate
tracks, opening compatibility, pause/resume, natural completion and skip. The
27 generated clips fit their timing windows; local transcription found no large
text mismatch, silent clip or clipped sample. These checks do not establish
in-game listening or a completed castle traversal.

Three reported route episodes remain unresolved: the Kids' Treasure Room chest,
Level crossing D in Upon Entering, and the Trap 3 conveyor. The supplied log lacks
their live floor or approach state. This update records bounded snapshots of
already captured route state when failures occur, so the next tester log can
explain them. Moving still may recover those cases.

All 3,235 managed tests passed: Core 219, Native 1,035, Prism 10 and Mod 1,971.
The release build had zero warnings and errors. Package-script tests 4, AMM
manifest tests 6, release-script tests 18, deployment-path tests 6 and canonical
path checks passed. Claude reviewed native blocker identity, menu stat policy
and movie/story lifecycle integration; the root agent verified the changes.
