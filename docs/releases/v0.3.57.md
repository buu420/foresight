# Foresight 0.3.57 beta

After the Tyranno Lair prison battle, the game places the party away from the
passage that reveals the prisoner. Foresight previously pointed to an interaction
without a listed person. The story objective now guides back through the native
passage, then switches to Kino's live interaction once he is drawn. The player
still presses Confirm. The hidden character is not listed or named in advance.

Both manual guidance and automatic walking use that approach. The earlier
"Break into the Tyranno Lair" objective now uses the correct encounter strip,
instead of including trap encounters in other disconnected rooms.

Some native maps hold multiple disconnected rooms or floors. Foresight was listing
guide exits, chests and interactions from all those sections, resulting in repeated
"No route" answers. A conservative physical-floor check now omits unseen,
unremembered guide destinations when separation is proved. Visible and remembered
targets remain identifiable and explain the restriction. Unknown floor cases are
retained, along with possible connections through verified native doors, drops
and stair landings. The check does not authorize movement or bypass native rules.

Research uses the tester's eight live scene-302 map snapshots, later actor and
story log entries, installed scene scripts and a fresh Ghidra export of the native
region selection, layer acceptance and Confirm scan. The post-battle floor comes
from the earlier capture: the native script establishes that the battle does not
change it. The per-load reveal guard remaining clear is inferred from that script.
Kino's final revealed position has not yet been captured live; navigation uses
his current native coordinates, not the scripted endpoint.

The existing opening/story recordings, three movie narration masters and movie
playback behavior are unchanged. Saves and installed movie packs are preserved.

All 3,271 managed tests passed: Native 1,035, Core 219, Prism 10 and Mod 2,007.
The release build had zero warnings and errors. Package tests 4, AMM manifest
tests 6, release-script tests 18, deployment-path tests 6 and canonical-path
checks passed. Claude researched and implemented the prison approach and
separately reviewed the floor filter; root verified the source and integration.
