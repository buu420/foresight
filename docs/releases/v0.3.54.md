# Foresight 0.3.54 beta

- Replaces screen-reader story-description speech with 124 Fish-generated clips
  using the creator's approved voice recording. Dialogue and menus retain the
  screen reader; existing movie narration is preserved.
- Covers the same verified gestures and opening/fair actions as 0.3.53, with
  appearance labels before introductions and for custom character names.
- Preserves captions in logs and braille, waits for voice clips before following
  dialogue and initial choices, and cancels narration at native scene/menu/battle
  boundaries. Failed clips or stalled audio devices fall back to Prism.

Players need no Fish account or API key. This remains selected coverage, not a
complete narration of every story scene or NPC.
See [voice implementation and timing limits](../story-voice-0354.md).

Tester focus: listen to the opening/fair, End of Time, mountain, Ioka and Reptite
Lair story actions. Check voice identity, pronunciation, dialogue/choice ordering
and cancellation when opening a menu or entering battle. Report missing, mistimed
or repeated descriptions with the latest Foresight log and the scene/save used.

NVDA 2026.1 does not expose prior speech completion through Prism. If you advance
while a previous line is still reading, it can overlap a voice clip. Following
speech waits for the recording to finish. Windows x86 playback and automated
checks passed; in-game listening of these recordings still needs testing.

All 3,105 managed tests passed (Native 1,030, Core 211, Prism 10, Mod 1,854),
with package, AMM manifest, release-script and deployment-path checks passing.
Local audio checks covered all 124 clips. Publication and installation evidence
will be recorded in the publication audit.
