# Foresight 0.3.86 beta

- The narrow passage in the logged present-day Dimensional Vortex room now has
  reachable approaches. Manual guidance, automatic walking and Story Events use
  the opening instead of aiming at the adjacent wall.
- Castle Dreamscape now lists its native opening passage under Exits. Story Events
  reaches that trigger first, then continues toward the encounter after the game
  opens the path. The instruction no longer names a concealed boss prematurely.
- These targets require their actual native script watchers. Passage labels do
  not preview the next randomized room. The treasure audit found no chest records
  in either affected room; existing chest targets elsewhere remain available.

Install with the game closed, using the standalone package or Accessibility Mod
Manager. This release includes earlier fixes, narration and movement assists.
It contains no crash collector.

For testing, load the present-day vortex save and try both the Vortex passage and
Story Events with manual guidance and automatic walking. In Castle Dreamscape,
try Castle passage under Exits and the current Story Events route from the entry
room. Check that Story Events continues after the passage opens. Let native
cutscenes and battles run, then restart navigation after room or control changes.
Use the game's Confirm for chests and other interactions.

Verification uses retained tester states, native script/Ghidra evidence,
regression checks and offline execution of the original x86 terrain movement.
This is not live gameplay, physical controller, audible speech or recipient-PC
installation proof. The separate map-texture crash investigation remains unresolved.
