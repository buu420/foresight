# Foresight 0.3.84 beta

Frozen Cliffs now lists six distinct cave entrances even when you face away from
them. Select a cave in Exits and start automatic walking to opt into the slide
assist. It follows the native downhill motion using ordinary running and
directional input, then moves Up into the entrance. Story Events follows a
forward cave; if you have slid too far down, it can guide you through a reachable
return cave and explain how to approach again from the top.

While running, hold Up to stop sliding during manual navigation. Manual guidance
uses the same directed routes and gives that instruction when it needs a new
route. If walking is selected, use the game's Dash control to enable running
before starting the assist again. The assist stops for manual control, loss of
focus, unavailable movement state, battles, native control loss and room changes.
Restart guidance after each native transition. It never presses Confirm.

All twelve native chests in the cliffs and adjoining passage have stable per-room
letters. Opening chest A does not rename chest B. Approaches preserve the game's
floor and facing requirements; press Confirm to open a chest. Some chests are on
separate ledges reached through different caves. No uphill route or hidden
reward information is supplied. Existing level-crossing targets remain available
where the current terrain supports them.

Close Chrono Trigger before updating. Refresh the buu420 beta source in
Accessibility Mod Manager, or extract the standalone ZIP beside the game
executable and run Install Foresight.cmd. Earlier fixes and narration remain
included. Saves, settings and other mods are preserved. No crash collector is
included.

Please test each cave, the forward Story Events route, and a return to the top
after overshooting an entrance. Try both guidance modes and the optional chest
branches. Check cancellation and restarting after encounters and room changes.
Send the complete gameplay log with the selected destination and Run setting if
guidance fails.

Validation uses the supplied 0.3.83 log, native scripts, Ghidra analysis and
initial resource maps. The log contains cliff poses and actor facts, but no full
Frozen Cliffs route-failure capture; test states are explicitly derived. Offline
execution of the original x86 terrain mover verifies six cave approaches and all
twelve chest approaches in both navigation modes. This excludes live actor and
encounter scripts, graphics and actual room transitions. Facing and trigger
checks use separately audited native rules. Physical controller input, audible
speech, live gameplay and behavior on the tester's PC still need testing. The
separate map-texture creation crash remains unresolved.
