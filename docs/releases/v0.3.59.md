# Foresight 0.3.59 beta

New Game name entry no longer stops with “Name exceeds the audited maximum of five UTF-16 code units” when the game displays a longer localized name. French and German use “Chrono,” and German also uses “Frosch.” The game's own default names are valid exceptions to its custom-name editing limit.

The reader announces the actual native name on entry, during character-grid or keyboard edits, when keyboard entry closes, and in the native confirmation. It no longer announces an inaccurate universal five-character maximum. The game continues to enforce its original naming restrictions, input, and confirmation behavior.

The shared saved-name reader also preserves longer localized names in battle, formation reserve cards, and navigation text. Accepting a native six-character default must not make those readers discard the character's name later.

The native audit checks default names for all nine installed game languages. Unicode names and native localized button/confirmation text are preserved. The mod's own announcements and recorded descriptions remain mainly English; this update does not claim complete translation of the mod.

All 3,396 managed tests pass. Regressions reproduce the original failure and verify six-character defaults, Unicode text, confirmation argument forwarding, and malformed-memory rejection. The tester's ZIP contains only loader logs, so the tester's language is still unknown. A live New Game test with the tester's settings, controller and screen reader remains needed. See the [native evidence and validation limits](../native-audits/2026-10-13-name-entry-localized-names.md).

Existing Tyranno Lair fixes, navigation, narration, voice packs, saves and settings are preserved. Close the game before updating. Use the standalone `Foresight-v0.3.59-beta-win-x86.zip` or Accessibility Mod Manager package `Foresight-v0.3.59-beta-amm.zip`.
