# Foresight 0.3.67 beta

Ocean Palace navigation now uses the full height of the great stair. Story
Events leads down the stairs while Masa is concealed, then offers his native
interaction when he appears. Disconnected chambers no longer offer one
another's objects as reachable targets.

Floor switches, wall switches and elevator controls have useful labels.
The bridge panel stays listed while inactive, with a clear restriction.
Routes account for the native encounters before the lower switches and
elevator. Manual guidance and auto-walk use the same verified destinations;
battles, locks, dialogue choices and Confirm remain under the game's control.
Restart navigation after a native cutscene or battle returns control.

Dalton, Masa, Mune and other supported story characters use names already
introduced by the game. Dalton's earlier approach-triggered conversation is
reachable from People. Lavos is a named story character; the cutscenes leading
to later battle maps no longer appear as ordinary exits.
Parked Algetty characters and premature off-camera Dalton entries are omitted.

New descriptions cover supported visible actions around the Mammon Machine
and Lavos. Movie 007, including its on-screen English text, has narration in
the approved voice for both original movie variants. It plays alongside the
original soundtrack. Earlier voice recordings are preserved unchanged.

This remains a beta. The earlier keep desktop crash is still unconfirmed.
Offline captured-map regressions and native movie playback checks do not
prove live Palace traversal, controller behavior or audible screen-reader
and narration output. Those tests remain needed.

See [the native and route audit](../native-audits/2026-10-17-ocean-palace.md).
Close the game before updating. Use `Foresight-v0.3.67-beta-win-x86.zip` for
standalone installation or `Foresight-v0.3.67-beta-amm.zip` through
Accessibility Mod Manager.

Validation: 4,162 automated tests and 28 release checks passed, with native
x86 movement/movie probes and Claude Opus 5.5 review. See the audit for limits.
