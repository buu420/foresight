# Foresight 0.3.51 beta — Forest Maze navigation

- The Forest Maze story route to the Reptite Lair uses the southern exit.
  Its two exits are labelled **Outside, north side** and **Outside, south side**.
- Walking routes account for native sideways movement along diagonal walls.
  Auto-walk keeps the required cardinal input, and manual guidance follows
  progress through the same movement. Spoken step counts include that travel.
- Holding Dash no longer sends auto-walk back across a level crossing. Both
  navigation modes refresh directions from the actual position after a stall.
- Ordinary level crossings with verified connections between physical layers
  appear as distinct navigation targets in areas with navigation guidance.
- A look-ahead audit found the same missing movement pattern in Reptite Lair,
  Giant's Claw and Death Peak. Installed-map regressions cover those cases.
