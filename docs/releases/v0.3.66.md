# Foresight 0.3.66 beta

The keep entrance door is now an identifiable object and a usable staged route
for **Exits**, **Story Events** and **Interactable Objects**, in manual guidance
and auto-walk. Navigation approaches the native opening contact on the closed
floor. If the opening sequence stops navigation, restart it when player control
returns. Native terrain, locks, story rules and Confirm remain under the game
and player's control.

The verified door-opening animation now triggers the existing **A passage
opens** recording in the approved narration voice. Earlier animation frames
and ordinary room reloads do not repeat it. Story Events also includes Ozzie's
native central-chamber interaction before continuing toward the next trap room.

Identical lights have stable **Glowing point A–D** labels in the pit room and
**A–B** labels beside the later boss room. Each is selectable in Objects and
Story Events; guidance does not secretly choose the correct one. A save function
is identified when the native saving cue is available on that light. Return
warps elsewhere are named, unopened invisible pits are omitted, and disguised
figures retain their visible appearance until they disappear or change.

The early keep scripts intentionally stop the music before the entrance-hall
introduction. The tester could not confirm which sounds were missing; audible
effects and output-device behavior remain unverified.

**The reported desktop crash is not confirmed fixed.** Its log contains no
crash stack. The external helper now logs memory counters once per minute and
the game's exit code. If the game closes again, include the gameplay log and
`Accessibility/Logs/bootstrap.log` so the next report has termination evidence.

All earlier fixes and 160 voice recordings are retained. Saves, settings and
original game files are preserved. Automated and offline native checks do not
replace live keep traversal, controller input or screen-reader listening.

Validation: 3,869 automated tests, including 53 new keep cases; 28 release
checks; 12 offline native door replays; and Claude Opus 5.5 review.

See [the native and route audit](../native-audits/2026-10-16-keep-navigation.md).

Close the game before updating. Use `Foresight-v0.3.66-beta-win-x86.zip` for
standalone installation or `Foresight-v0.3.66-beta-amm.zip` through Accessibility
Mod Manager.
