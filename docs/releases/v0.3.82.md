# Foresight 0.3.82 beta

Temporal Research Lab's warp maze now identifies its fifteen pads with unique
letters and landing-area names. Select the current Story Events objective, a pad
or another available destination, then use manual guidance or automatic walking.
When a warp is needed, guidance announces the next reachable pad and leads to its
native interaction. Each warp reloads the room: restart guidance from the new
landing. Optional branches remain available.

Story Events reaches the security chamber door before asking you to enter the
closed exit. Follow the final facing instruction and press the game's Confirm
button yourself. Once the door opens, the objective continues through the actual
exit. The conveyor room's warp-maze entrance also uses its native opening contact.
Room and doorway labels distinguish the conveyor room, warp maze and security
chamber. Passwords, battles, locks, party choices and Confirm remain native.

This public update also includes the previously unpublished0.3.81 Lost Sanctum
fixes: current-area and current-era quest priorities, the open Lightless Cave
entrance, Waystone and Nu/builder contacts, fortress passages, and spoken walking
controls for Winding Passage turns. The unfinished bridge retains its native
restriction. Earlier fixes remain included.

Close Chrono Trigger before updating. Use Accessibility Mod Manager's buu420
source and beta channel, or extract the standalone ZIP beside Chrono Trigger.exe
and run Install Foresight.cmd. Saves, settings, narration and unrelated mods are
preserved. No crash collector is included.

Please test the warp maze from its entrance and each landing, the optional pad
branches, the security door and the return route after administrator registration.
Retest both navigation modes and the Lost Sanctum changes. Send the complete
Reloaded gameplay log for missing labels or failed routes, including the selected
destination and Run setting.
