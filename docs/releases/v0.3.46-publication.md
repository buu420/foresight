fixes. End of Time pillars have fixed numbers, repeated exit names have letter
suffixes, and routes can approach the door from any valid starting facing and

## Verification

All **2,575 managed tests** passed against the committed source: Native 888,
Core 195, Prism 8, Mod 1,484. These include the supported executable identity
and 176 native hook byte contracts. Four release-package tests, six AMM manifest
tests and eighteen release-script tests passed. The fresh release build had
zero warnings or errors, and the packaged DLL identifies the tagged source
commit. An independent reviewer passed 69 focused checks with no actionable
findings. Claude's native review confirmed the facing guard and bounded stage
proof; fresh read-only Ghidra output independently verifies the facing helper.

The standalone passed every payload hash, supported-game installer verification,
private x86 runtime launch and altered-payload rejection. The AMM package passed
identity and content validation with 277 files. All 275 wrapped standalone files
match byte-for-byte, as do all 28 mod-package files. Its manager script remains
staging-only. The final repaired AMM hash, rather than the pre-repair build hash,
is recorded in the catalog.

All three uploaded asset sizes and digests matched before publication. Each
published asset was then downloaded without authentication and matched its
local hash. The ordinary public catalog URL was also read without authentication
and matched the entire committed catalog. Assets were published and verified
before publishing the catalog record. The catalog has no trust errors,
unobtainable releases, authoring problems or publication blockers.

Local deployment passed **303 checks with zero failures**. All 275 installed
public files, including the 28 mod-package files, match the anonymously downloaded
standalone ZIP. The manifest ownership set remains the same. The two owned README
files and checksum receipt were refreshed from that verified ZIP with backups.

`Accessibility/Backups/20261008-103812-762-076ade32`.

Installed `Setup-Foresight.ps1 -Mode Verify` passed. All forty protected files,
including the original executable, game data and separate narration pack,

## Tester scope

The [release notes](v0.3.46.md) request both navigation modes from the starting
pillar platform, from the old man's room while facing different directions,
and after returning from Spekkio. Check stable light numbers and repeated exit
labels. **Live movement, speech listening and controller delivery were not
performed for this release.** Confirm and story interactions remain native;
the earlier bike, race and party-menu behavior is retained. If a passage or
speech fails, provide the latest Chrono Trigger text log.
