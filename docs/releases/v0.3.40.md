# Foresight 0.3.40 — Initial Public Beta

Foresight brings screen-reader menus, dialogue and battle information, distance-based footsteps, spoken directions and automatic walking to the **Windows Steam edition of Chrono Trigger**.

**This is a beta.** Story and optional-destination data span the game, but the entire game has not been verified through a complete accessibility playthrough. Routes, menus, encounters and minigames can still need fixes. Please report missing announcements and failed routes.

## Download and install

Download **Foresight-v0.3.40-beta-win-x86.zip** below, not GitHub's automatic source-code archive. Close the game, extract the ZIP's contents beside `Chrono Trigger.exe`, and run **Install Foresight.cmd**. Approve the administrator prompt and installer confirmation, then launch normally through Steam with your screen reader running.

The ZIP includes the portable loader, hooks, Prism and a private x86 .NET 9 runtime. Use the classic game interface. The supported Steam app is 613830, executable version 2.0.0.1; the installer verifies the exact executable hash.

To remove the mod, run **Uninstall Foresight.cmd** and wait for successful registry removal before deleting files. Shared files, narration packs, backups and saves should be preserved. Full installation, removal, compatibility and troubleshooting instructions are in the [README](https://github.com/buu420/foresight#readme).

## Keyboard navigation

| Key | Action |
|---|---|
| U / O | Previous / next category |
| J / L | Previous / next destination |
| K | Repeat destination and current direction/instruction |
| I | Start spoken step-by-step guidance while you move |
| P | Start or stop automatic walking |
| F8 | Toggle footsteps for the current session |

Categories: **People, Exits, Interactable Objects, Story Events and Enemies**. Save points are under Interactable Objects. Available Story Events do not require prior destination discovery. You still press the game's Confirm button to interact.

## Controller navigation

| PlayStation / Xbox button | Action |
|---|---|
| Right-stick click / R3 | Open or close the spoken navigation menu; opening stops the current route |
| L1 / LB | Previous category while the menu is open |
| R1 / RB | Next category while the menu is open |
| D-pad Up / Down | Previous / next destination while the menu is open |
| Square / X | Close the menu and start automatic walking |
| Cross / A | Close the menu and start spoken guidance |
| Circle / B | Close the menu |

Release the closing/start button and return the stick to neutral before ordinary game input resumes. Steam Input must pass right-stick click through as R3. The user's controller setup has been tested; not every device/layout has been verified.

## Battle keys

| Key | Action |
|---|---|
| 1 / 2 / 3 | Choose the party member to inspect |
| Shift+H | Read that member's current and maximum HP |
| M | Read that member's current and maximum MP |
| K | Repeat current command or target |

Press Shift before H; plain H retains its native game action. Inspection does not issue commands or pause Active combat. Mod shortcuts require game focus and no Ctrl, Alt or Windows key. Use Shift only for Shift+H.

## Coverage and limitations

Includes classic main/submenus, Settings, Extras, dialogue and choices, Save slots, shops, supported battle menus, local/world/vehicle navigation, encounters, save points, story objectives, classic optional quests and PC bonus destinations. Some interface variants, icons, effects, result states and live route conditions remain unverified. Touch-interface inventory/equipment/tech/party/shop readers and comprehensive minigame access are not implemented.

This public package includes **no game files or private voice pack**. Separately prepared movie narration is supported and an existing local pack is preserved; scene actions and NPC gestures are not comprehensively described.

The FFVII chats confirmed the Accessibility Mod Manager publishing process. Foresight's catalog entry is **deferred** because the manager currently removes files even if required registry cleanup is declined or fails. Use the standalone ZIP until that uninstall issue is resolved. [Integration findings](https://github.com/buu420/foresight/blob/main/docs/mod-manager-release.md).
