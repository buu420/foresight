# Foresight 0.3.54 publication audit

[Public beta](https://github.com/buu420/foresight/releases/tag/v0.3.54), published
2026-10-10 at 22:59:49 UTC. Immutable source/tag commit:
`985cc11f4a49da797d1133ead7fa3e7a7e5db959`.

The release contains 124 Fish-generated story-description recordings from the
approved natural-voice reference. These use the existing native action coverage;
dialogue and menus remain on Prism. Players need no Fish credentials. Private
model metadata, the API key and original human recording are excluded.

In-game listening of these recordings remains unperformed. Installed NVDA 2026.1
does not report prior speech completion through Prism, so early advancement can
overlap prior screen-reader speech with the recording. Following dialogue and
initial choices wait for actual recording completion. See the
[voice timing notes](../story-voice-0354.md).
