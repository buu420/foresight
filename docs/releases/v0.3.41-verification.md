# Foresight 0.3.41 verification

Release source: `f8812a3`, tag `v0.3.41`. Catalog addition: `buu420/buu-s-mods` commit `66b36ee`.

- 2,414 managed tests passed: Core 192, Native 861, Mod 1,353, Prism 8.
- Native cold-load test passed 3,000 joystick/timer calls. All 192 named WinMM exports and 193 ordinals matched the system library. A DLL initialized through the injection helper called WinMM successfully.
- 24 installer/manager-script tests passed in PowerShell 7 and Windows PowerShell 5.1. Canonical-path and mapped-drive checks also passed in both shells.
- Standalone package: 275 archive files, complete checksum coverage, native x86/asInvoker manifests, private .NET 9.0.20 executed, missing game and modified payload rejected.
- Temporary standalone install/uninstall removed 274 listed files and preserved the game and unlisted user files.
- AMM author CLI validated the package and index. The staged preinstall hook ran in a temporary game folder; its seven install actions installed 275 files. File-receipt removal preserved user files. The temporary preinstall script is retained inside the archive and excluded from install actions. No post-install or post-uninstall hook exists. The manager UI itself was not automated.
- Normal Steam startup with both legacy IFEO views clear activated NVDA and the required hooks. The native proxy received the managed-ready acknowledgement; startup announcements were logged. No gameplay input was sent by the agent. On game exit the previous Reloaded pointer was restored.
- Final installed verification: 303 passed, 0 failed. The executable, installed movie-description manifest and three previously narrated movie files retained their pre-deployment hashes.
- Public release is a prerelease, not a draft. Uploaded asset sizes and GitHub SHA-256 digests matched local packages. The public raw catalog returned the beta record and matching AMM hash. The two FFVII definitions and 114 existing release records were preserved.
