# Foresight 0.3.81 tester build

Lost Sanctum's Lightless Cave entrance now has usable approach points before and
after it is lit, including routes across the map's floor levels. An unrelated
village encounter no longer removes the cave connection. The Waystone uses the
reachable native interaction shared by the stone and its pedestal.

The Nu Master and Reptite bridge builder have identifiable People entries. Both
navigation modes can reach their native interaction positions on the narrow
bridge. The unfinished span remains blocked and is labeled accordingly.

The Primeval Fortress's touch-opening doors provide usable routes through the
native opening interaction. Story Events inside the Sanctum follows current
accepted errands, preserves parallel choices, and keeps new local requests in
People until accepted. It does not send a Sanctum objective toward Lavos.

Winding Passage auto-walk can select a shorter native walking step at tight
corners when the current Run setting permits. For manual guidance, use walking
speed at those corners. A setting that forces running may require changing the
game's Run setting or using its Dash control. Native puzzles, battles, timing
and Confirm remain under the game and player's control.

Close Chrono Trigger before installing. Extract the standalone ZIP beside
Chrono Trigger.exe and run Install Foresight.cmd. Saves, settings, narration and
unrelated mods are preserved. The crash collector is not included.

Please test:

1. Follow an accepted Sanctum errand through item collection, hand-in and era
   changes. Inside the Sanctum, check that Story Events keeps an appropriate
   active objective. On the world map, select the desired Sanctum errand.
2. Reach the Lightless Cave in both navigation modes before and after lighting
   it. Retest from the different floor levels encountered on the approach.
3. Select the Waystone and the bridge's Nu and builder. Check the native
   interaction after arrival. The bridge must retain its normal construction
   requirements.
4. Navigate through each available fortress door. Check that auto-walk waits
   for the game to open it and continues through the resulting passage.
5. Retest Winding Passage corners and chest routes, including the Steel Ingot
   route. Report the Run setting if movement still stalls.

Offline checks are recorded in the handoff. Live gameplay, physical controller,
audible speech and tester-PC installation remain separate checks. The supplied
log identifies its build as 0.3.79; the same failures were also reproduced against
the published 0.3.80 DLLs. The separate native map-texture crash remains unresolved.
