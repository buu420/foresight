# Foresight 0.3.49 beta — Denadoro mountain transitions

- Verified drops and slides are selectable scenery targets, including
  **Drop to lower path**, **Slide drop A/B/C**, and **Lower path drop**.
- Ordinary paths joining the map's walking levels have distinct **Level crossing
  A/B/etc.** labels where the native collision data proves the connection.
- Manual guidance and automatic walking can plan an exit through a verified
  drop. They guide you to its approach, describe continuing down, wait while the
  native game moves the party, and continue from the observed landing position.
- Routes preserve each drop's direction and native one-use restrictions. Some
  exits still require entering the map from another connected area.
- Keyboard and controller routes survive the verified native movement pause.
  Other actions, lost focus, controller loss and unverified cutscenes still stop
  automatic walking.

Close the game before updating. Please test both navigation modes from the upper
path in Denadoro Map 2 and the slide paths in Map 3, including the two drops
in sequence. Check the named level crossings and use Repeat at a drop approach.
Include a fresh Chrono Trigger text log if a route or announcement fails.
