# Foresight 0.3.69 beta

Testing candidate for the approved Death Peak shelter-holding preference.
Includes the Death Peak, Ocean Palace and Blackbird fixes from
[0.3.68](v0.3.68.md).

After automatic arrival at a pushed shelter tree, the mod says **Holding Up for
shelter** and keeps the native Up input held. Keyboard category/destination
browsing and the controller navigation menu preserve this hold. Take manual
control or select a destination and start its route when you choose to leave.
If a new route cannot start, the mod says **Still holding shelter** and keeps
holding. P on the current shelter stops holding. Manual guidance still says **Hold Up
now** and leaves holding to the player. Arrival on native push-free floor stops
normally.

Holding requires fresh native control, the same verified shelter and the
player's precise horizontal alignment within its protected area. Losing game
focus, controller ownership, native movement authority, coherent state or the
shelter contact cancels it. Holding uses plain Up in every native run mode;
running remains necessary for climbing against the stronger push.
No gust schedule, departure, Confirm, combat or game physics is
automated.

All four regression suites pass **4,356 tests**, including native-map fixtures,
navigation-menu and input-lifecycle checks. Package/deployment checks are
separate from gameplay.
No live game, physical controller or audible speech test has been performed
for this candidate. Wind/contact timing still needs tester traversal.
