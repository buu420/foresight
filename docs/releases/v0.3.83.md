# Foresight 0.3.83 beta

This update repairs the reported randomized Dimensional Vortex route. Manual
guidance and automatic walking can follow the full Ocean Palace staircase to its
native lower passage. The canyon doorway appears as one usable destination,
rather than three overlapping markers with one unreachable centre. Local exits
use distinct Vortex passage labels without revealing the next random room.

Story Events follows the current native connection through the conveyor rooms.
The conveyor exit door is an Interactable Object and the first local objective
while closed. Follow its facing instruction and press Confirm yourself. After
it opens, restart guidance to continue through the current passage. Restart
guidance after each native room transition. Battles, locks and Confirm remain
under the game's control; automatic walking stops when native control is lost.

Temporal Research Lab, Lost Sanctum and earlier fixes remain included. This is a
focused repair of the reported rooms, not proof that every random vortex seed
or room has been played through.

Close Chrono Trigger before updating. Refresh the buu420 source and beta channel
in Accessibility Mod Manager, or extract the standalone ZIP beside the game
executable and run Install Foresight.cmd. Saves, settings, narration and other
mods are preserved. No crash collector is included.

Please test both navigation modes through the canyon doorway, conveyor rooms and
Ocean Palace staircase, including each native encounter and room transition.
Send the complete Reloaded gameplay log if a passage is missing or guidance
fails, with the destination selected and the current Run setting.

Validation uses six exact captures from the supplied 0.3.82 log, native scripts
and Ghidra analysis. Conveyor entrance and exit-door cases use explicitly derived
initial-resource states. Fifteen complete staircase controller traces also pass
offline execution of the original x86 terrain mover: 21,209 movement frames using
the original 64-row property planes. That check disables scene jumps and excludes
actor and encounter scripts. Separate managed replays use transcribed movement
rules. None of these checks proves live transitions, physical-controller input,
audible speech or behavior on the tester's PC. The separate map-texture creation
crash remains unresolved.
