# Foresight 0.3.47 beta — closed doors and Main Room

This build addresses the tester's missing door and unavailable return route in
Spekkio's room. It also removes the character-name spoiler from the End of Time
hub's spoken room name.

- **Objects → Door to the main room** identifies Spekkio's return doorway.
  **Exits → End of Time platform** can route through it from any valid starting
  facing. The final approach moves down to open the native door, then continues
  after the game supplies opened floor. Re-entering the room works the same way.
- Verified automatic tile-copy passages now continue into their opening contact.
  This includes ordinary Guardia Castle doors checked against installed scripts
  and terrain. Key, switch, story and Confirm requirements remain in force.
  Terrain triggers with additional unaudited effects keep their existing behavior.
- The End of Time hub is announced as **End of Time, Main Room**, including
  catalog destination labels.

**Live testing remains needed.** Test manual guidance and automatic walking out
of Spekkio's room while facing up, left and right, including after re-entry.
Check the Objects doorway entry and Main Room announcement. Also try ordinary
doors known to open by walking into them. If speech or navigation fails, include
the latest Chrono Trigger text log. Close the game before updating.
