# Foresight 0.3.45 beta — End of Time and bike targets

This test build addresses the October 7 feedback after a tester reported clearing
the Factory and completing the Site 32 race on 0.3.44.

- **Interactable Objects → Jet bike** tracks the native bike interaction in both
  Site 32 parking lots, including later visits. Press Confirm yourself to use it.
- **Exits → Pillar of light** tracks the lights currently drawn at the End of Time.
  Complete the introduction and magic lesson before using the starting pillars.
  The game's Confirm prompt reads each destination.
- Routes can reach the native touch triggers that open the platform stairs and
  the room behind the old man, then continue after the captured floor opens.
  Spekkio's actual actor class now supports the introduction, return after three
  laps, and lesson restart objectives.
- The classic End of Time party-change scene uses the Party reader for the
  visible roster, focus, locks, held member and combinations. Normal game controls
  change the party. A page that cannot be read announces that failure.

**Live End of Time testing remains needed.** Check the route from the initial
pillar platform to the old man, entering Spekkio's room, completing or restarting
his lesson, returning to the platform, and opening/changing/closing the party
screen. Check spoken guidance and automatic walking separately. Please include
the latest Chrono Trigger text log if speech or a route fails.

Validation: **2,550 managed checks passed** (Native 888, Core 195, Prism 8,
Mod 1,459), including the supported executable identity and 176 native hook byte
contracts. The release build had zero warnings or errors. These checks do not
establish live controller input, speech, or a completed playthrough.
