# Foresight 0.3.48 public beta

Published October 9, 2026, following the user's approval of all six battle,
party-menu and Dash fixes and continuing authorization to release test builds
and deploy locally. Closing a menu cancels its queued speech; ally selection
reads visible HP/MP; zero HP is described as knocked out; native Dash can remain
held during field/world auto-walk; reserve members read saved names; unchanged
combo lists no longer repeat with every party focus change.
