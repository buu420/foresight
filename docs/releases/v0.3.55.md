# Foresight 0.3.55 beta

The opening movie now has the creator's recorded narrator voice when the original
movie is installed. Version 0.3.54 recorded the supported story actions but left
the opening fallback on the screen reader. This release adds 22 Fish recordings
from the same approved voice reference, matching the existing descriptions and
timings. All 124 story recordings remain unchanged.

Only descriptions accepted for the current opening and its current generation
can start a recording. Leaving the opening cancels its active and queued clips,
including exits that produce no spoken announcement. Unmatched description text
still goes through Prism. A working narrated movie pack suppresses the fallback.
Dialogue, menus and native controls retain their existing behavior.

The previously approved separate-track movies were restored on the development
installation after original movie files were found beneath a stale narration
manifest. Their hashes and original backups were verified. The public ZIP does
not distribute game movies, the original human recording or Fish credentials.

Focused regressions cover opening voice selection, captions, stale generations,
wrong screens, unmatched text and cancellation. Every opening WAV fits its shot's
time window; local transcription found no large text mismatch, silent clip or
clipped sample. The native x86 topology check selected the original soundtrack,
narration and video together. See the publication audit for final release checks.

In-game listening is still needed. Please test the opening normally and by
skipping it, then report missing, overlapping or late narration with the latest
Foresight log. Story coverage remains incomplete. Earlier unfinished screen-reader
speech can overlap a recording; following dialogue waits for its completion.

All 3,113 managed tests passed (Native 1,030, Core 211, Prism 10, Mod 1,862).
The release build had zero warnings and errors. Package tests 4, AMM manifest
tests 6, release-script tests 18, deployment-path tests 6 and canonical-path
checks also passed. The code and narration timing received a separate review.
See [opening narration details](../opening-voice-0355.md).
