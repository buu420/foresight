# Foresight 0.3.63 beta

The **Entrance security terminal** in the Derelict Factory now remains available
in Interactable Objects and binds the **Deactivate the entrance security** story
objective. Manual guidance and auto-walk use its native Confirm approaches.
The player presses Confirm; the game checks whether Robo is in the active party
and runs his security override.

The underlying party reader now accepts the game's empty and vacated roster
markers. Previously these normal values could make the entire roster unreadable,
which hid party-gated interactions. Empty slots remain empty; they are never
converted into recruited or active characters. Unreadable or invalid data still
remains unavailable.

Before the override, selecting either onward lift explains that entrance
security is active and points to the terminal. These barriers remain in place
until the game opens them. The return exit to the world map stays usable.
After the native opening, both lifts resume ordinary navigation.
An unreachable staircase from another room sharing the map is also removed
from this entrance's object list.

The log, installed script and terrain, native decompilation and offline route
regressions support this repair. Both navigation modes are checked from the
three logged entrance positions. The log does not contain the raw party-roster
words or live terrain planes, so the roster mismatch and installed-terrain
reproduction are distinguished from captured live state.

All earlier narration, including the opening and Epoch movies, is retained
without regenerating recordings. Saves, settings and original game files are
preserved. Live Factory traversal, controller behavior and screen-reader
listening still need tester confirmation.

See [the native audit](../native-audits/2026-10-15-factory-entrance.md).

Close the game before updating. Use `Foresight-v0.3.63-beta-win-x86.zip` for
standalone installation or `Foresight-v0.3.63-beta-amm.zip` through Accessibility
Mod Manager.
