# Foresight 0.3.71 tester build

Death Peak's wind entrance now offers **Exits → Climb windy slope with shelter assist**. Start automatic walking on that destination to climb to the lower tree, hold shelter through a gust, continue to the upper tree when the gust ends, and then continue to the next map after another gust. Each departure follows the live wind cue. Starting partway up uses the remaining shelters.

Prepare the attempt from the **2300 A.D. world map → Exits → Arm Death Peak climbing assist**, using automatic walking on that option. Then enter the mountain yourself and release all buttons until walking starts. Other actions at entry cancel the preparation. The assist starts as soon as you regain control, so you can finish choosing the option before entering the wind. This arm is used once, including when the attempt fails; it never rearms after a knockback. Opening the game menu, losing focus or disabling accessibility cancels it, with the reason spoken when navigation becomes available again. Select the option again to disarm it. You can also start the in-map assistance destination yourself.

Keyboard: P starts automatic walking. Controller: R3 opens navigation, L1/LB or R1/RB changes category, and Square/X starts automatic walking. The assist controls Run during its legs, using the native run setting. If running is off, follow the spoken prompt to enable it. Move manually, use a game action or stop navigation to cancel. Loss of native player control or shelter contact stops movement.

Browsing the navigation menu while sheltered retains cover. A gust ending while the menu is open is skipped; the assist waits for a subsequent complete cue after the menu closes. If the next leg is blocked, it keeps holding shelter. A temporary unreadable wind or Run setting also keeps a separately verified shelter hold, announces the pause and prevents departure until a fresh complete cue is observed. Starting partway up first uses nearby cover. If the doll still requires interaction, the assist stops below it and leaves speaking and Confirm to you. Existing individual shelter routes and manual guidance remain available.

The native floor reading can be unavailable while standing at the entrance. Ordinary movement can begin on the gentle entry tiles without that reading; the steep slope still requires a readable running setting. Wind-timed departures always require fresh wind data.

The wind announcements describe why walking cannot overcome the stronger push, without repeatedly instructing an automatically walking player to press Run. This addresses the confusing prompt heard in the tester's recording while automatic walking was handling movement.

Install with the game closed, copy the standalone ZIP contents beside `Chrono Trigger.exe`, and run `Install Foresight.cmd`. Saves, settings and separately installed narration are preserved. The crash collector is supplied separately as **Foresight-Crash-Collector-v1.1.0.zip**; copy its three files beside the game executable if needed.

The rendering crash remains under investigation. The October 21 dump matches a failed map-texture creation request, and the new diagnostics make fragmented virtual address space a strong lead. This update retains those diagnostics and does not patch the renderer or executable. After another crash, run `Collect Foresight Crash Logs.cmd` before restarting and send its ZIP with the action, location and approximate time, plus any new dump.

Automated captured-map and navigation regressions cover the staged wind behavior and cancellation. Actual controller input, wind timing, trunk contact and audible announcements still require the tester's gameplay. This is not a completed live climb.
