# Foresight 0.3.41 beta

Foresight now loads from files in the Chrono Trigger game folder. Fresh installations, Steam launches and uninstalling need no registry entries or system runtime settings. This removes the old launch-registration dependency and allows normal file-based installation and removal through Accessibility Mod Manager.

- The native x86 proxy forwards Windows multimedia/controller calls independently of accessibility startup.
- The helper validates the game process and temporarily leases Reloaded configuration, restoring it when the game closes.
- Startup checks that Prism and the accessibility hooks actually became active.
- Older Foresight-owned launch registrations are removed once during migration. Fresh installs do not request this action.
- All keyboard, controller and battle controls are included in the README and manager description. Controller navigation behavior is unchanged from the user-tested 0.3.40 build.

Download **Foresight-v0.3.41-beta-win-x86.zip** for manual installation. The **Foresight-v0.3.41-beta-amm.zip** asset is for Accessibility Mod Manager and is referenced by the [buu420 author catalog](https://raw.githubusercontent.com/buu420/buu-s-mods/main/index.json). The runtime and loader dependencies are included.

This remains a beta. Full story and optional-destination catalogs are present, but a complete end-to-end accessible playthrough has not been verified. Routes, menus and encounters can still need corrections, and minigames are not comprehensively accessible. Use the classic interface. The release contains no original game files or private narration recordings and preserves separately installed descriptions.

Validation: 2,414 managed tests passed, plus native cold-start forwarding, full WinMM export-name/ordinal parity, and forwarded calls during DLL initialization. Installer tests passed in PowerShell 7 and Windows PowerShell 5.1. A normal Steam launch activated NVDA and the accessibility hooks, and exit restored the previous Reloaded configuration. The supported executable and installed narration files retained their original hashes. The manager package is schema-validated and exercised in temporary folders; the manager UI itself was not automated.
