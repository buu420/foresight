# Foresight 0.3.77 tester build

Black Omen's elevator now gives a local forward destination through general Story Events. Depending on the native stop, it selects the existing elevator sparkle or doorway instead of sending the party toward a previous room or the End of Time. Manual guidance and auto-walk share that destination.

An unknown stop gives a readable status with no route. If the selected control is unavailable, Story Events does not substitute another stop's control. The existing Interactable Objects, elevator quest entries, pad and northern-door fixes remain included. Native movement, rides, battles, progression and player Confirm remain under the game's control.

Close Chrono Trigger before installing. Extract the standalone ZIP beside Chrono Trigger.exe and run Install Foresight.cmd, or update the buu420 author source's beta through Accessibility Mod Manager. Saves, settings, narration and unrelated mods are preserved. This package has no crash collector.

Regression fixtures exercise all four stops, native precedence, unavailable state, both guidance modes and the connection from the pad room into the elevator. The new elevator fixture uses native actor anchors and logged player positions with explicit synthetic open-floor geometry; it does not prove live traversal. Existing pad/door fixtures remain. Live gameplay, physical controller, audible speech and recipient-PC installation tests remain pending.

The separate Dimensional Vortex report still needs a fresh completed-save world-map log. This update does not change vortex unlocking or claim a rendering-crash fix.
