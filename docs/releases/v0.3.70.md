# Foresight 0.3.70 diagnostic tester build

This build adds diagnostics for the map-texture creation failure identified in
six tester crash dumps. It does **not** fix the crash yet.

When native texture creation fails, the mod records the requested dimensions,
rendering scale, estimated allocation and available memory information in
`Accessibility/Logs/render-texture.log`. Successful requests produce no new
gameplay announcements. The crash collector now includes this log.

Install this ZIP over the existing mod with the game closed, then run
`Install Foresight.cmd`. Play normally. If another crash occurs, run
`Collect Foresight Crash Logs.cmd` **before restarting the game** and send its
ZIP with the location, action and approximate time. Please retain any new
Windows dump files as well. Collection does not upload anything automatically.

Previous Death Peak shelter holding, Ocean Palace and Blackbird fixes remain
included. Saves, settings, game movies and separately installed narration are
preserved. This diagnostic change does not add new story descriptions.

Native evidence and limitations are recorded in the
[crash audit](../native-audits/2026-10-20-render-texture-crash.md).
