# Foresight 0.3.60 publication audit

Published October13,2026: [Foresight 0.3.60 beta](https://github.com/buu420/foresight/releases/tag/v0.3.60).

Source/tag commit: `75b52197a2aa50b895710f90e7f0c851676a3bce`. This audit follows in a documentation commit; the release tag and packages remain tied to that source commit.

The visible Guardia Forest clearing gate now has its verified native Confirm capability before first use. Objects and Story Events offer it at the chase stage. Manual guidance and auto-walk use existing native approaches and facing/dispatch checks, and the player presses Confirm to enter. Other portals and hidden destinations are unchanged. See the [native evidence and validation limits](../native-audits/2026-10-13-forest-gate.md).

## Verification

- All **3,410** managed tests passed: Native **1,056**, Core **226**, Prism **10**, Mod **2,118**. Five positive regressions failed before implementation; nine exclusion cases passed. The fixed tests cover both categories and navigation modes, native Confirm selection, hidden/invalid actors and retirement after hiding.
- Final packaged contracts: **32** passed. Release package tests **4**, AMM manifest tests **6**, installation/removal script tests **18**, deployment-path tests **6**, and the canonical-path check passed. Package build completed with zero warnings and errors.
- Native script research and independent review through Claude Teammate were read-only. Root verified the supported executable hash and exported Confirm/scan/dispatch and packed-map decoding functions with Ghidra12.1.2. Review found no actionable issues.
- Deployment passed **303** checks. Installed verification passed again after the public documentation refresh. All **275** installed files match the anonymously downloaded standalone release; all **28** managed package files match. The **277**-entry AMM package contains matching payload bytes plus its manifest and staging script.
- All **40** protected game/movie files, **149** existing source narration WAVs, voice manifest declarations, and **10** save/settings files were preserved. The manifest's pre-existing checkout line endings normalize identically to the previous tag. No narration was regenerated.
- GitHub's three uploaded assets matched local sizes and SHA-256 before publication. Anonymous downloads matched afterward. The release is public, tagged `v0.3.60`, and marked prerelease.
- AMM Author CLI **0.30.0** validated and published to `buu420/buu-s-mods`, branch `main`. Catalog commit: `862b739dd12c6c3e3caa2a619d618f4598eb04a4`. The ordinary public index matches the complete committed catalog and new AMM digest. The fresh catalog baseline was `da559da6e840de114eaffe622443fc7e8a1b1648`; historical and unrelated records remain intact.
