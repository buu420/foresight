# Foresight 0.3.78 tester build

Navigation now excludes time spent in its own synchronous capture and speech from a connected controller's poll timeout. This prevents a slow navigation update from closing the spoken menu or cancelling a newly selected walk. Actual input pauses, disconnections, scene changes and manual control still stop movement. Menu-only resets now record a reason and timing in the gameplay log.

World-map entrance routes choose a contact clear of a parked Epoch or Dactyl boarding area. If a vehicle covers every usable entrance contact, the target explains that it needs repositioning. Boarding and entering still require your own Confirm. Native collision and landing rules remain unchanged.

Inside the Dimensional Vortex, the primary Story Events selection follows the local vortex objective. Unavailable progress or a missing local control gives a readable status without falling back to the general Lavos route. Existing optional entries remain available in their categories. World maps, the End of Time and Geno Dome keep their existing main objective.

Close Chrono Trigger before installing. Extract the supplied standalone ZIP beside Chrono Trigger.exe and run Install Foresight.cmd. Saves, settings, narration and unrelated mods are preserved. This package does not include the crash collector.

Please retest browsing several categories without reopening the menu, guidance and auto-walk to the parked Epoch, entering the vortex after landing, and Story Events within its entrance and shifting rooms. Send the complete Reloaded gameplay log if any of these stalls or chooses the wrong passage.

Offline tests cover slow capture and speech, real controller gaps, native entrance coordinates with explicit synthetic terrain and boarding shapes, nonaligned walking phases, both guidance modes and missing/unreadable local progress. The tester's log proves entry into the future vortex on 0.3.77; it does not record why each old menu reset happened. The timeout repair is a reproduced failure mechanism, and the new diagnostics support checking any remaining cause. Live gameplay, physical controller, audible speech and recipient-PC installation tests remain pending.
