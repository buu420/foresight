# Foresight 0.3.65 beta

Mountain of Woe's onward route can now finish searching from the two player
positions in the latest report. Both **Exits** and **Story Events** use the fix
in manual guidance and auto-walk. The return exit remains available.

The search previously stopped at 131,072 distinct positions before finding
the valid route around the mountain's walls and bridges. Its finite ceiling
is now 262,144. Native terrain, layers, actor contacts and progression rules
still determine where a route can go.

Sixteen new offline regressions cover both reported positions, both navigation
commands, the onward exit and story target, the return exit, smaller caller
budgets, and simulated native walking across the map. These use installed
initial terrain and reconstructed logged actor facts; the report does not
contain a full live capture of this map.

All earlier fixes and 160 voice recordings are retained. Saves, settings and
original game files are preserved. Live traversal, physical controller input
and screen-reader listening still need tester confirmation.

See [the native and route audit](../native-audits/2026-10-16-mountain-woe.md).

Close the game before updating. Use `Foresight-v0.3.65-beta-win-x86.zip` for
standalone installation or `Foresight-v0.3.65-beta-amm.zip` through Accessibility
Mod Manager.
