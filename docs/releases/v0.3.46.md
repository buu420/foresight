# Foresight 0.3.46 beta — distinct exits and End of Time door

This build addresses the tester's report that the End of Time lights are
indistinguishable and the door behind the old man is unavailable in both
navigation modes. The tester confirmed that the bike and lights now appear.

- **Pillar of light 1–9** gives each End of Time light a fixed number. The first
  three keep their numbers as more lights appear. Press Confirm in the light
  to read the game's destination prompt.
- Repeated exit names now receive **A, B, C** suffixes in field, world-map and
  flight navigation. Assigned suffixes persist for the current area and mode.
- The door route can be planned while facing down, left or right, and its final
  approach moves up. Routes from the pillar platform can handle the stairs and
  door in sequence, waiting for the game to open each passage. The game's story
  restrictions still apply.

**Live testing remains needed.** Check manual guidance and automatic walking
from the pillar platform to the door, from the old man's room while facing
different directions, and after returning from Spekkio. Check the light numbers
and repeated exit names. If speech or navigation fails, include the latest
Chrono Trigger text log.
