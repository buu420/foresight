# Foresight 0.3.72 tester build

Black Omen's teleport pads now appear in **Interactable Objects** with **Teleport pad to…** labels. Pads remain identifiable while the game's arrival guard prevents an immediate return trip, with room-specific reactivation directions. An unreadable activation state prevents automatic travel and explains why.

Both navigation modes can reach the narrow pad before the lower elevator. The lower landing also uses the game's wrapped collision data, allowing routes to its pad and elevator exit. The two disconnected landings remain separate.

After the lower elevator, **Northern door** replaces the generic scenery label. The door opens when the party walks into its native contact. Guidance reaches the usable side and explains the approach; auto-walk finishes with an ordinary Up movement. During the verified opening script, guidance stays active and automatic movement pauses. The route resumes from a fresh completed capture, and selecting the door itself reports that it is open. Its exit is named **Passage through the northern door**.

In the reported pad rooms and door corridor, the late-game **Story Events → Continue through Black Omen** route uses the local forward pad, passage or door. It no longer substitutes a return trip toward the End of Time gate in these rooms.

Close the game before installing. Extract the standalone ZIP beside `Chrono Trigger.exe` and run `Install Foresight.cmd`. Saves, settings and separately installed narration are preserved. Native locks, encounters, script control and player Confirm remain authoritative. If a native encounter or transition stops navigation, restart it when player control returns.

This candidate retains the Death Peak assist. The tester reported passing Death Peak; that report does not replace local controller, speech or end-to-end gameplay verification. The renderer crash remains unresolved, with existing diagnostics retained. No new narration assets are included in this change.

Offline regressions use installed initial terrain, the log's actor facts and explicitly recorded reconstruction assumptions. The single supplied log contains live route snapshots for earlier rooms, but none for the final corridor. Actual Black Omen traversal, physical controller input and audible announcements still need tester verification.
