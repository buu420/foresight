# Foresight 0.3.74 tester build

Sunken Desert chest routes now prefer native interaction positions suited to the moving sand, with other approaches retained when the preferred position cannot be reached. Both guidance modes use the live terrain, layers, chest grid and native interaction rules. Automatic walking counters sideways drift with ordinary directional input and the native Run control. It continues trying to keep a closed chest in reach until you open it, cancel, take manual control or the game starts an encounter. Press Confirm, or keep it held, to open the chest. Foresight never supplies Confirm.

Manual guidance stays active when sand carries you away from the interaction. It gives updated directions after you release movement, names diagonal input to counter sideways drift, and remembers failed approaches across those pauses. It does not move the character. Run is needed to move against the sand. In Run modes where holding Dash selects walking, release Dash for automatic travel. If walking is toggled on, briefly tap and release Dash to select running, then restart automatic walking. The mod explains these cases and preserves the native setting.

Floor feedback calls the terrain shifting sand. Automatic direction changes are coalesced and queued so that they do not interrupt route guidance. Repeat still reads the current direction and applicable Run advice. A navigation-menu reset no longer wrongly leaves the floor's Run setting unavailable when starting a route.

Close Chrono Trigger before installing. Extract the standalone ZIP beside `Chrono Trigger.exe`, then run `Install Foresight.cmd`. Saves, settings, narration and unrelated mods are preserved. Existing North Cape, Bekkler, Death Peak and Black Omen changes remain included. The separate rendering crash remains unresolved; this build contains no crash collector.

Validation includes the tester log, matching-executable Ghidra evidence, regression tests and offline original-code movement replay for all eleven chest targets in both Desert rooms. The replay uses initial terrain and closed chests, omitting native encounters, other actors and the full outer actor/rendering loop. It demonstrates movement and repeated Confirm windows, not a completed live playthrough. Manual input, audible screen-reader output, actual encounters and recipient-PC installation still require tester verification. No local game or Steam launch was performed.
