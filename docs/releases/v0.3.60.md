# Foresight 0.3.60 beta

The visible time gate in Guardia Forest's clearing now appears in Interactable Objects before the player first uses it after the prison escape. Story Events also offers “Approach the Time Gate” at the native chase stage. Previously the list contained the sealed box but omitted the gate, and Story Events had no destination.

Manual guidance and auto-walk use the gate's native interaction geometry and facing. Arrival asks the player to press Confirm; opening the gate and changing areas remain native game actions. Hidden, removed, unloaded or unverified gate states are excluded, and the label does not reveal where the gate leads. This repair does not change unrelated portal placements.

All 3,410 managed tests pass. Regression tests use the tester's gate/guard positions and installed initial terrain. They cover both navigation modes in Objects and Story Events, native Confirm selection, hidden/invalid states, and retirement when the gate hides after interaction. Ghidra and the installed script establish the native handoff between the gate and its controller. Live traversal, controller and screen-reader testing are still needed. See the [native evidence and validation limits](../native-audits/2026-10-13-forest-gate.md).

The previous localized naming repair, Tyranno Lair routes, narration, installed voice packs, saves and settings are preserved. Close the game before updating. Use `Foresight-v0.3.60-beta-win-x86.zip` for standalone installation or `Foresight-v0.3.60-beta-amm.zip` through Accessibility Mod Manager.
