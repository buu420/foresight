# Foresight 0.3.59 publication audit

Published October 13, 2026: [Foresight 0.3.59 beta](https://github.com/buu420/foresight/releases/tag/v0.3.59).

Source/tag commit: `dce3803fe4ded2d0de628c17b2e7338fc2a85a78`. This audit is a later documentation commit; the release tag and binaries remain tied to the source commit above.

The fix removes an incorrect five-character read constraint from native Name Entry and its Core narration, and from the shared saved-name reader used by battle, formation reserve identity and navigation. The game still owns editing, defaults and confirmation. [Native evidence, multilingual coverage and limits](../native-audits/2026-10-13-name-entry-localized-names.md).

## Verification

- All **3,396** managed tests passed: Native **1,056**, Core **226**, Prism **10**, Mod **2,104**. Regression fixtures failed before implementation for the reported six-character-name failure and for subsequent battle/navigation name loss. The failed-test artifacts are retained privately.
- The final packaged build passed **32** manifest, package, movie narration and story-voice contract tests. Release package tests **4**, AMM manifest tests **6**, installation/removal script tests **18**, deployment-path tests **6**, and the canonical-path check passed.
- Package build completed with zero warnings and errors. Source-commit metadata in the released Mod DLL matches the tag. Independent Claude reviews were read-only; the shared-reader finding was fixed and the follow-up review cleared it.
- Deployment passed **303** checks. Installed verification passed again after the public documentation refresh. All **275** installed payload files match the anonymously downloaded standalone release; all **28** managed package files match. The **277**-entry AMM package contains the same payload bytes plus its staging script and manifest.
- All **40** protected game/movie files, **149** existing source narration WAVs, the voice manifest declarations, and **10** save/settings files were preserved. The source manifest's existing Git checkout line endings differ from tag bytes; declarations normalize identically. No narration was regenerated.
- GitHub's three uploaded assets matched local size and SHA-256 before publication. All three assets downloaded anonymously afterward and matched again. The release is public, tagged `v0.3.59`, and marked prerelease.
- AMM Author CLI **0.30.0** validated and published the beta catalog to `buu420/buu-s-mods`, branch `main`. Catalog commit: `2989ec2b74827b9300b7f72511ffd5e83d5d686c`. The anonymously fetched ordinary public index matches the entire committed catalog, including the release digest. Prior Chrono releases and unrelated games/releases are preserved.
