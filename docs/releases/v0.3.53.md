# Foresight 0.3.53 beta

- Adds short spoken descriptions for 57 reviewed character animation mappings
  during native scenes and dialogue. This includes the first six party characters
  through Ioka, Reptite Lair and their subsequent appearances.
- Adds seven specific opening/fair cues: the curtains, Mother's departure,
  leaving bed and stretching, the collision, standing up, and hopping.
- Queues descriptions with dialogue, uses current names after introductions,
  and suppresses hidden/offscreen actions and repeated animation ticks.
- Keeps the Ioka contest observer, native player choices and installed movie
  narration intact. These descriptions use the screen reader without an API key.

This is selected verified coverage, not complete narration of every scene or NPC.
See [coverage and native evidence](../story-actions-0353.md).

Tester focus: start a fresh New Game, then compare named character gestures in
saved scenes at the End of Time, mountains, Ioka and Reptite Lair. Report missing,
mistimed or repeated actions, speech interrupted by a description, or descriptions
of someone who is not visible. Supply the Foresight log and the save/scene used.

All 3,049 managed tests passed (Native 1,030, Core 211, Prism 9, Mod 1,799),
along with package, AMM manifest, release-script and deployment-path checks.
Regression tests cover native action proof, script loops, scene visibility,
dialogue ordering, battle resets and keeping one original native call.

The live New Game attempt was stopped with Escape, so gameplay timing and
screen-reader listening remain unverified. Nine backed-up save/settings files
were checked afterward and are unchanged. See the publication audit for final
package, public-download and local-deployment verification.
