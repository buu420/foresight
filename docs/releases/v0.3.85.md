# Foresight0.3.85 beta

Temporal Research Lab navigation repairs:

- The conveyor room's patrol-room door now has a useful label and reachable native
  opening contact. Manual guidance and automatic walking use that contact before
  continuing through the real doorway.
- Robot detection zones no longer appear as exits or stop a route before the actual
  exit cell. The real patrol, conveyor, holding and control rooms have distinct names.
- Story Events follows the native console, rescue and automatic release sequence,
  then the available onward passage. It no longer returns to an inactive console.
- The side-room door and its treasure branch become reachable when the native
  barrier opens. Earlier barriers remain identifiable and blocked.
- Visible robots have stable A–E labels and current facing directions. Their native
  detection and capture behavior remains active; facing reports describe the pose
  currently visible, and do not promise a safe crossing.
- Rapid conveyor/still-floor changes no longer repeat the same warning over route
  guidance. Repeat still reports the current floor. These32-speed belts retain
  their native one-way movement, including while running.

Install with the game closed using the standalone package or Accessibility Mod
Manager. This release includes earlier fixes, narration and the Death Peak/Frozen
Cliffs assists. It contains no crash collector.

For testing, load the lab save and try both manual guidance and automatic walking
to Story Events and the named doorways. Continue up at a touch door when guidance
requests it. Use the game's Confirm for consoles, chests and the warp maze's
security-chamber door. Check the side-room chests after the native barrier opens.
Restart navigation after room changes and battles. A robot can still capture the
party and send it to the holding room; that is a native hazard rather than an exit.

Verification uses exact retained tester states, native script/Ghidra evidence,
regression checks and offline native terrain movement. These are not live gameplay,
physical controller, audible speech or recipient-PC installation tests. The separate
native map-texture crash investigation remains unresolved.
