# Foresight 0.3.80 tester build

Geno Dome now identifies its terminals, individual switches, charging and receiver pods, elevator doors, figurines and two Sentinels. The three wall switches have distinct left, middle and right labels. A selected visible switch reads its displayed red or green lamp, and visible lamp changes are announced once. Pods report their verified open or closed state. Receiver-door openings and laser-barrier changes have short cues. Selected nearby controls describe those visible obstacles, and failed routes name a closed obstacle when its native opening copy proves the connection.

The electrical aura names the party leader when it appears and gives a fading cue when it ends. Receiver pods keep the charge, matching the game. The mobile Sentinel reports waiting, following, returning to its post and stopping beside the guard Sentinel. Navigation repeat includes the currently observed charge and following status. These mechanism cues queue after current guidance.

Both navigation modes use the native pod entrances and Sentinel contacts. Auto-walk stops repeating the charging contact once the game accepts it; step away before entering again. While the Sentinel follows, choose the destination you want to lead it toward. Geno Dome auto-walk can select a short native walking step for narrow turns, while preserving native wall slides, facing turns and contact pushes. A setting that forces running still needs your native Dash control or Run setting changed for a walking-only corner. Follow the separate running instruction against the conveyor. The conveyor exit door stays identifiable after it opens and says to continue up. Puzzle choices, native timing, battles and Confirm remain under the game and player's control.

Close Chrono Trigger before installing. Extract the standalone ZIP beside Chrono Trigger.exe and run Install Foresight.cmd. Saves, settings, narration and unrelated mods are preserved. The package does not include the crash collector. The separate native map-texture crash remains unresolved.

Please test:

1. Browse Interactable Objects and People throughout Geno Dome. Check the distinct terminals, switches, pods, figurines and Sentinels.
2. Select nearby wall switches and operate them with the game's controls. Check lamp colors and single change announcements. A distant offscreen lamp should stay silent.
3. Open and enter the charging pod using manual guidance, then auto-walk. Check that navigation stops at the accepted contact, the electrical cue names the current leader and follows the visible aura, and entering a receiver does not falsely announce lost charge. Check the receiver's door-opening cue and laser-barrier changes.
4. Start the mobile Sentinel following, lead it to another destination, and check waiting/following feedback. If a battle sends it back, check the return cue. Check the meeting route with both guidance modes.
5. Try the long conveyor, both elevator doors and the main-room exit with your usual Run settings. Check for blocked movement, unwanted repeated input or missing arrival cues.

Send the complete Reloaded gameplay log for missing labels, incorrect or repeated cues, or failed routes. Include the selected destination, guidance mode and Run setting when possible.

Offline checks use the tester's six captured maps, installed scripts and graphics, owned-memory capture fixtures, and original x86 movement replay. The repaired gait policy preserves all 695 previously successful cases in 1,132 paired route replays and reaches three additional cases. The oracle does not execute actors, battles, Confirm or exit scripts; arrival at those contacts is an offline result.
