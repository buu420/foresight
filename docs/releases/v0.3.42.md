# Foresight 0.3.42 beta — Arris Dome rat chase

Automatic walking now stays active when it reaches the moving rat, and pressing or holding Confirm no longer cancels the chase. It announces when the rat can be caught and continues following its live position. The same behavior works from Story Events and the ordinary Rat entry.

Select Catch the rat, start auto-walk, then hold your usual game Confirm button. Movement keys, other game actions, P, or reopening the controller navigation menu still stop automatic walking. If the rat escapes, leave the rafters and return to retry.

The game still decides whether the catch succeeds. **The complete catch still needs an in-game test.** Please report whether you can catch the rat and advance the story, and attach the latest Reloaded log if pursuit stops or the catch fails. This beta does not add support for the other minigames.

Download **Foresight-v0.3.42-beta-win-x86.zip** for manual installation. Accessibility Mod Manager uses **Foresight-v0.3.42-beta-amm.zip** through the [buu420 author catalog](https://raw.githubusercontent.com/buu420/buu-s-mods/main/index.json). Close the game before updating. Both packages include the runtime and loader dependencies; existing saves and separately installed narration are preserved. See the [README](https://github.com/buu420/foresight/blob/v0.3.42/README.md) for installation and all keyboard/controller controls.

Validation: all 2,437 managed tests passed, including 23 new rat-chase checks. Offline route checks use the installed rafter terrain and native interaction rules; they do not prove a completed live catch. The standalone package passed file-hash, private-runtime and installer verification.
