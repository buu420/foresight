# Foresight 0.3.87 beta

- Volcano's two visible switches in the present-day Dimensional Vortex now appear
  under Interactable Objects. Guidance reaches the native interaction tile and
  asks you to use Confirm to examine the switch. The game's choice menu remains
  under your control.
- Story Events follows the actual passages to the first switch's separate ledge.
  Reaching another section of the same map no longer ends the route at a note.
- Narrow warp openings have approaches that fit the player's body. Switch
  effects no longer appear as walk-on exits before the player makes a choice.
- A verified Volcano corner now uses walking speed when the current Run setting
  permits it. Manual guidance explains the native Dash control. If the setting
  forces running, automatic walking stops and explains how to select walking.
- Nearby chest routes are checked, including the upper chest that requires the
  later switch. Collected chests disappear normally; unopened restrictions remain.

Install with the game closed, using the standalone package or Accessibility Mod
Manager. Earlier fixes, narration and movement assists are included. There is no
crash collector in the release.

For testing, load the bookmarked Volcano save. Select Story Events and try manual
guidance and automatic walking to the first switch. Examine Switch under
Interactable Objects, then make your own choice in the game. Continue to the later
switch and test the nearby treasure routes. Check the walking cue with your usual
Run setting. Restart navigation after battles and room or control changes, and
use the game's Confirm for switches and chests.

Verification uses retained tester states, native scripts/Ghidra evidence,
regression checks and offline execution of the original x86 terrain movement.
Live gameplay, physical-controller input, audible speech and recipient-PC
installation remain to be tested. The separate map-texture crash investigation
remains unresolved.
