# Foresight 0.3.88 beta

- Bonus areas use their loaded native location names where available, including
  localized entry announcements. Destination labels still use the existing English catalog.
  Native soft line breaks no longer introduce stray commas in
  destination labels.
- Bonus enemies use their native names. A unique enemy has no extra letter;
  actual identical targets keep stable identifiers throughout the battle.
  Empty slots do not create duplicates. Unreadable names retain an identifiable
  fallback. Selecting a named target avoids repeating the same native name popup.
- The Volcano passage fixes are included and checked against two more captured
  failure positions, in both navigation modes at walking and running speeds.
  Story Events and nearby chest routes retain native switch restrictions.
- Two previously uncovered native films, Flight of the Dactyls and What Comes
  to Pass, have 27 descriptions in the approved narrator voice. Existing opening,
  movie and story recordings are retained. The gallery no longer incorrectly
  announces that movie descriptions are unavailable.

Install with the game closed, using the standalone package or Accessibility Mod
Manager. Previous fixes and movement assists are included. There is no crash
collector. Native choices, locks, timers, battles and Confirm remain under game
control.

For testing, revisit the bookmarked Volcano room and select its passage and Story
Events with manual guidance and auto-walk, at walking and running speeds. Check
nearby unopened and collected chests. In bonus areas such as Lost Sanctum, listen
for the location name, then compare unique enemies and duplicate enemies while
targeting and during damage feedback. Party HP/MP and actual battle messages
should remain readable. The two films can also be checked through unlocked
gallery entries; test completion and native skipping with your screen reader.

Descript was attempted, but its editor could not render the imported footage.
The new descriptions were checked against timestamped local frames, then generated
with the existing approved Fish voice. This adds specific verified coverage; it
does not establish descriptions for every visual action in the game.

Automated tests, exact packaged x86 checks and offline execution of original
native movement and movie playback are recorded separately. Live gameplay,
physical-controller input, audible speech and recipient-PC installation remain
to be tested. The separate map-texture crash investigation remains unresolved.
